# XAUUSD Risk Calculator

เครื่องคิดเลขบริหารความเสี่ยงสำหรับเทรดทอง XAUUSD บนบัญชี XM Ultra Low Micro

## สเปกสัญญา (GOLDm#)

| รายการ | ค่า |
|---|---|
| Contract size | 1 oz ต่อ 1 lot |
| Min lot | 0.1 |
| Lot step | 0.01 |
| Max lot | 100 |
| Stops level | 0 |
| สกุลเงิน | USD |
| Spread (ค่าเริ่มต้น) | 0.03 |
| Leverage (ค่าเริ่มต้น) | 1:1000 |

## หลักการทำงาน

ยึดความเสี่ยงเป็นเงินคงที่ — ปรับ SL แล้ว lot เปลี่ยนตาม, ปรับ lot แล้ว SL ขยับ สเปรดถูกบวกเข้าไปในระยะ SL แล้ว

## สูตรคำนวณ

```
lot = riskMoney / ((slDist + spread) × contractSize) ปัดลงตาม lotStep
realRisk = lot × (slDist + spread) × contractSize
margin = price × lot × contractSize / leverage
```

## ความเป็นส่วนตัว

ค่าพอร์ต ความเสี่ยง และการตั้งค่าทั้งหมดเก็บอยู่ใน localStorage ของเบราว์เซอร์บนเครื่องผู้ใช้เท่านั้น ไม่มีการส่งข้อมูลออกไปที่ใด ไฟล์นี้ไม่มีการเชื่อมต่ออินเทอร์เน็ตเลย

## การตรวจสอบความถูกต้อง

ควรเทียบค่า Margin ที่เครื่องมือคำนวณกับช่อง Margin ใน MT5 หลังเปิดออเดอร์จริง ถ้าไม่ตรงให้ใช้ส่วน Calibrate ในหน้า Settings กรอกออเดอร์จริงเพื่อให้ระบบคำนวณ contract size ที่ถูกต้องกลับมา

## คำเตือน

เครื่องมือนี้เป็นตัวช่วยคำนวณเท่านั้น ไม่ใช่คำแนะนำการลงทุน ผู้ใช้รับผิดชอบการตัดสินใจเทรดของตนเอง
